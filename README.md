# Wallace Office Site Localization Roadmap

Repeatable process for localizing the 11 Wallace office agent sites (cloned from the Nelson/Maryville site) so each ranks for its own town and county. Twin Lakes (Lenoir City) is the model.

- **[ROADMAP.md](ROADMAP.md)** — every change in order, Howard's rules, design system, mechanics, per-office checklist (also rendered as [index.html](index.html)).
- `templates/` — the Twin Lakes HTML blocks (home `block.html`, `office.html`, `footer.html`, `buyers.html`, `sellers.html`, `relocation.html`, `contact.html`; `*_body.html` = body-only sections).
- `scripts/` — Playwright/CDP scripts that apply blocks in Beaver Builder, hide menu items, set Yoast meta.
- `img/` — Twin Lakes images used in the blocks.
